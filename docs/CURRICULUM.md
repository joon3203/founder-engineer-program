# Founder Engineer Program — 커리큘럼 v1.0

## 목표
- Python 중심의 독립 코딩 실력을 갖춘다.
- C로 메모리·시스템 개념을 익힌다.
- 필요시 TypeScript를 사용해 실사용 SaaS를 배포한다.
- 12주 동안 첫 유료 SaaS 매출 30만 원에 **도전**한다. 성과는 보장하지 않는다.

## 트랙
1. **Python 핵심:** 변수·제어문·함수·컬렉션·모듈·예외·파일·객체지향
2. **알고리즘:** 시간복잡도·자료구조·재귀·정렬·탐색·그래프·DP (기본 언어 Python)
3. **C/CS:** 포인터·동적 메모리·연결 리스트·컴퓨터 구조·운영체제·네트워크
4. **제품 개발:** Git·테스트·HTTP/API·FastAPI·SQL·인증·보안·배포·TypeScript(필요 시)
5. **마케팅/사업:** 시장 조사·온라인 고객 발굴·인터뷰·가치 제안·가격·유료 전환·운영

## 12주 사업화 실험 — 일정은 목표이며 수업 진급은 실력 기반
| 기간 | 제품·시장 단계 | 개발 학습 |
| --- | --- | --- |
| 1~2주 | 시장 후보 비교, 자발적 고객 인터뷰 모집 | 적응형 진단, Python 기본기·Git |
| 3~4주 | 문제 검증, 제품 아이디어 공동 평가 | 자료구조·웹·SQL 기초 |
| 5~7주 | 검증된 문제의 MVP 제작 | FastAPI·DB·테스트·디버깅 |
| 8~10주 | 공개 배포, 고객 피드백, 가격 실험 | 운영·보안·프론트엔드 |
| 11~12주 | 유료 전환 시도, 결과 회고 | 품질 개선·기술 부채 관리 |

검증 실패 시 시장/제품을 바꾼다. 12주가 지나도 통과하지 못한 CS 단원은 계속 학습한다.

## 언어 우선순위
- Python: **1순위**, 알고리즘 기본 풀이 언어 및 SaaS 백엔드
- C: **2순위**, 학교 수업 및 컴퓨터과학 개념 실험
- TypeScript: **3순위**, 실제 웹 UI에 필요해질 때 학습

## 다음 단계
1. 초기 진단(아직 응시 전)
2. 약점 분석 및 첫 단원 배치
3. 짧은 문답 → 직접 구현 → 코드 리뷰 → 새 문제로 검증
4. 제품의 사용자 반응과 프로그래밍 성적을 별도로 기록

학습 강도는 시간 할당보다 통과 기준과 컨디션을 우선한다.
