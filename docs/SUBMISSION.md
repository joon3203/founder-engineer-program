# 과제 제출 방법

1. 과제별로 `exercises/`, `challenges/` 또는 `04-saas-project/` 폴더에 파일 생성.
2. 네가 먼저 구현하고 테스트 결과 기록.
3. Git에 커밋하고 과제 파일 경로 혹은 PR 링크 공유.
4. AI 튜터가 검토: 정확성 35, 설계 25, 코드 품질/테스트 20, 효율성 20.
5. 피드백과 재검증 후 `progress/grades.md`, `progress/weaknesses.md` 업데이트.

독립 코딩 과제에서는 AI가 완성 코드를 생성하지 않으며 힌트는 기록합니다. 실제 제품 작업에서는 AI 사용을 허용합니다.
