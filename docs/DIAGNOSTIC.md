# 초기 진단평가 운영안

- **진단은 배치평가**: 합격/불합격이 아니며 기존 진급시험 85점 규칙은 적용하지 않음.
- 평가 영역: Python 기본기(25), 알고리즘·문제해결(30), C/CS(20), 실전 개발·디버깅(25).
- 적응형 진행: 쉬운 문제를 해결하면 심화로, 막히면 원인 탐색.
- 첫 풀이에는 AI 코드 생성 금지. 외부 참고/힌트를 받은 경우 기록.
- 제출: 코드 + 실행 결과/테스트 + 간단한 풀이 설명.
- 성적표에는 분야별 현 수준과 우선 보완 개념만 기입. 성과나 점수 미리 추정하지 않음.
- 진단 후 첫 수업 단원을 배정.
