## 2026-11-10 — Python 초기 진단: 참조·복사
- 문항 1: `b = a; b.append(4); print(a)`에서 `[1,2,3]` 답변 → 오답. 동일 리스트 객체 참조 개념 보충.
- 문항 1-2: `b = a.copy(); b.append(4)`에서 a=[1,2,3], b=[1,2,3,4] 정답. C의 메모리 개념과 연결해 설명함.
- 지도 메모: Python 이름 바인딩과 얕은 복사/중첩 가변 객체 구분 필요. 진급 평가는 아직 실시하지 않음.

### Python 진단평가 2 — 얕은 복사와 중첩 리스트
- 제시: `a=[[1,2],[3,4]]; b=a.copy(); b[0].append(5); b.append([6,7])`
- 답안: `a=[[1,2,5],[3,4]]`, `b=[[1,2,5],[3,4],[6,7]]` — 정확.
- 설명: 얕은 복사에서 내부 리스트 참조가 공유된다는 사실을 이해함. `set` 대신 `list` 용어 교정.
- 임시 문항평가: 10/10 (이 문항만 해당). 단원 진급시험 미실시.

### Python 진단평가 3 — 참조 재할당과 가변 객체 수정
- 답안: `a=[[1,2],[3,4,5]]`, `b=[[9,9],[3,4,5]]` 정확.
- 설명: `b[0]`의 새 리스트 참조 할당과 `b[1].append(5)`의 공유 객체 수정을 구분함.
- 문항평가: 10/10. 객체 참조·얕은 복사 **기초 진단 통과** (정식 진급시험 아님).
- 용어 보충: '집합'보다는 '리스트 객체'가 정확함.
- 다음 진단: 함수·딕셔너리·독립 코드 작성.

### Python 진단평가 4 — 딕셔너리 빈도 계산 (진행 중)
- 제출: `fruits = {}; for i in sales: fruits[i] += 1` 형식으로 시도. 반복 접근은 타당함.
- 관찰: 존재하지 않는 키를 `+= 1`로 증가시켜 `KeyError` 발생, `return` 누락.
- 지원: 사전 키 할당과 `if i not in fruits` 조건을 설명. 전체 해답은 제공하지 않음.
- 평가 보류: 사용자 수정 답안 대기. 정식 점수·진급 여부 미판정.

### Python 진단평가 4 — 딕셔너리 빈도 계산 (수정 답안)
- 제출 코드: `if i not in fruits: fruits[i] = 1; else: fruits[i] += 1` 후 `return fruits`.
- 출력 기대값: `{'사과': 3, '바나나': 2, '포도': 1}` — 정확.
- 피드백: 키 존재 확인, 값 초기화, 누적, 반환 모두 성공. 평균 시간복잡도 O(n).
- 학습 평가: 10/10 (수정 답안의 정확성), 힌트 사용 후 해결. 독립 구현 진급평가는 아직 미실시.
- 다음 평가: 유사한 새 문제를 독립 구현하여 전이 여부 확인.
