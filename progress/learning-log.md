## 2026-11-10 — Python 초기 진단: 참조·복사
- 문항 1: `b = a; b.append(4); print(a)`에서 `[1,2,3]` 답변 → 오답. 동일 리스트 객체 참조 개념 보충.
- 문항 1-2: `b = a.copy(); b.append(4)`에서 a=[1,2,3], b=[1,2,3,4] 정답. C의 메모리 개념과 연결해 설명함.
- 지도 메모: Python 이름 바인딩과 얕은 복사/중첩 가변 객체 구분 필요. 진급 평가는 아직 실시하지 않음.

### Python 진단평가 2 — 얕은 복사와 중첩 리스트
- 제시: `a=[[1,2],[3,4]]; b=a.copy(); b[0].append(5); b.append([6,7])`
- 답안: `a=[[1,2,5],[3,4]]`, `b=[[1,2,5],[3,4],[6,7]]` — 정확.
- 설명: 얕은 복사에서 내부 리스트 참조가 공유된다는 사실을 이해함. `set` 대신 `list` 용어 교정.
- 임시 문항평가: 10/10 (이 문항만 해당). 단원 진급시험 미실시.

### Python 진단평가 3 — 참조 재할당과 가변 객체 수정
