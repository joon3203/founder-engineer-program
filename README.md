# Founder Engineer Program

**Python 중심 독립 코딩 + 실사용 SaaS 창업 + 온라인 고객 발굴 교육과정**

## 지금 상태
- 운영 준비 완료, **초기 실력 진단 미실시**.
- 12주: *첫 사업화 실험 목표 기간*, 기술 습득은 실력 기반 진급제.
- SaaS 매출 30만 원: **도전 목표**, 보장하지 않음.
- Python 1순위(알고리즘), C 2순위(CS·메모리), TypeScript 3순위(필요한 웹 UI).
- 개념 학습·과제·진급시험은 **직접 코딩**. 실제 SaaS 프로젝트에서는 AI 도구 사용 가능.
- 소크라테스식 강의: 질문 → 추론 → 개념 설명 → 직접 구현 → 리뷰.
