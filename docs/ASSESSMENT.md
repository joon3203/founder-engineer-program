# 평가 체계

## 초기 진단(총 100점, 배치용)
- Python 기초: 25점
- 알고리즘/문제해결: 30점
- C/컴퓨터과학: 20점
- 실전 개발/디버깅: 25점

문항은 학습자의 답에 따라 난도를 바꾸는 적응형이다. 답을 모를 경우 모른다고 답해도 된다. 목적은 출발점 파악이다.

## 단원 종합평가(총 100점)
| 요소 | 점수 |
| --- | ---: |
| 기능의 정확성 | 35 |
| 문제 분석·설계 | 25 |
| 코드 품질·테스트 | 20 |
| 시간·공간 효율성 | 20 |

통과 = 85점 이상 + 필수 테스트 + 주요 개념 설명 가능.

## 과제 유형
- **Drill**: 짧은 개념 확인, AI 코드 생성 금지
- **Challenge**: 낯선 문제 독립 구현, AI 코드 생성 금지
- **Project**: 서비스 구현, AI 도구 활용 허용(검증 책임 필수)

## 증거의 종류
- 코드와 실행 결과
- 테스트 입출력 및 실패 사례
- 본인 설명과 복잡도 분석
- Git 커밋, 개선 이력
- 사업에서는 인터뷰·가입·유료 전환의 실측치(민감정보는 비공개)

평가 결과는 확정 사실과 검증하지 못한 부분을 구분해 기록한다.
